# Mission Control Dashboard

Frontend placeholder for the visual dashboard.

## Planned stack
- React
- game-like isometric layout
- agent activity scene
- event feed
- mission status panels
- optional Supabase auth and persistence

## Current status
- Vite + React scaffold running
- Dashboard reads `public/snapshot.json` generated by the Python runtime
- Dashboard also attempts a WebSocket live feed and falls back gracefully to snapshot polling
- Mock snapshot remains as fallback when runtime data is unavailable
- First mission room scene and KPI overview implemented

## Local workflow
- Install deps: `npm install`
- Run dev server: `npm run dev`
- Export runtime snapshot: `python3 ../../runtime/python/export_snapshot.py`
- Build production bundle: `npm run build`

## Next implementation steps
